# Аналитика рынка Новосибирска 2026 — лендинг СОДА

Страница сбора заявок: в обмен на контакты менеджер по продажам вручную отправляет PDF с региональной аналитикой по Новосибирску и ссылку на банк креативов СОДА.

Превью: https://nellkhamid-cmd.github.io/nsk-analytics-landing/

## Состав

```
index.html                 вся разметка, стили и скрипты (один файл, без сборки и зависимостей)
assets/fonts/              Manrope 400 / 500 / 600 / 800, woff2
assets/img/                логотип, фото Новосибирска, 6 креативов, 4 скриншота лендингов (webp)
README.md, .nojekyll       только для GitHub, на сервер не нужны
```

Все пути относительные — папку можно выложить в корень домена или в подпапку как есть.
Внешние запросы: только `mc.yandex.ru` (Метрика, когда указан номер) и ссылки на `sodaa.ru/policy`, `sodaa.ru/agreement`.

## Перенос на домен — чек-лист

1. Залить `index.html` и папку `assets/` целиком.
2. Метрика: в `<head>` заменить `window.METRIKA_ID = null` на номер счётчика (см. ниже).
3. `og:image` в `<head>` сейчас относительный (`assets/img/hero-nsk.webp`) — для превью в мессенджерах заменить на абсолютный URL: `https://<домен>/assets/img/hero-nsk.webp`.
4. Фавикон в странице не задан — браузер возьмёт `/favicon.ico` домена, если он есть.
5. Подключить приём заявок (CRM) — `CONFIG.endpoint`, см. ниже.

## Яндекс Метрика

Код счётчика уже стоит в `<head>` (блок `Yandex.Metrika counter`). Достаточно вписать номер:

```js
window.METRIKA_ID = 12345678;
```

Пока там `null`, счётчик не загружается, а цели пишутся в консоль браузера (удобно для проверки).
Если вставляете свой стандартный код счётчика — удалите наш блок, но оставьте строку `window.METRIKA_ID = <номер>;`, по ней отправляются цели.
Для посетителей без JavaScript в том же блоке закомментирован `<noscript>` — раскомментировать и вписать номер.

### Цели

В Метрике создать цели типа **«JavaScript-событие»** с идентификаторами:

| Идентификатор | Когда срабатывает | Параметры |
|---|---|---|
| `form_fill` | заполнил форму: все обязательные поля заполнены верно (один раз за визит) | `form`: `hero` / `final` |
| `form_submit` | отправил форму: прошла проверку и отправлена | `form`, `channel` |
| `click_phone` | клик по ссылке `tel:` | — |
| `click_email` | клик по ссылке `mailto:` | — |
| `click_telegram` | клик по ссылке на `t.me` | — |

Клики ловятся по всем ссылкам страницы, включая добавленные позже. Названия целей меняются в объекте `GOALS` в начале скрипта.

## Форма и CRM

Настройки — объект `CONFIG` в начале `<script>` внизу `index.html`:

- `endpoint` — адрес приёма заявок. Пусто — форма показывает «Спасибо», но заявка никуда не уходит (данные пишутся в консоль). При локальном открытии внизу слева видна плашка «Демо-режим».
- Отправка: `POST`, `multipart/form-data`, `mode: 'no-cors'` (ответ сервера не читается; заявка считается отправленной, если не было сетевой ошибки). Если нужен разбор ответа или JSON — правится в обработчике `submit`.
- `policyUrl`, `agreementUrl` — политика и согласие (сейчас sodaa.ru).
- `manager` — контакты менеджера в подвале (в HTML уже стоят те же значения).

Поля заявки:

| Поле | Обязательное | Значение |
|---|---|---|
| `name` | да | имя |
| `phone` | да | `+7 (XXX) XXX-XX-XX` |
| `company` | да | компания или ЖК |
| `channel` | да | `Telegram` / `WhatsApp` / `MAX` / `Почта` |
| `email` | если `channel = Почта` | почта |
| `consent` | да | `да` |
| `form` | авто | `Первый экран` / `Финальный блок` |
| `offer` | авто | `Аналитика рынка Новосибирск 2026 + банк креативов` |
| `page` | авто | URL страницы с UTM |
| `sent_at` | авто | дата и время (ru-RU) |
| `utm_source` … `utm_term` | авто | если есть в адресе |

## Прочее

- `?noanim` в адресе — показать все блоки сразу без анимации (для скриншотов).
- Форма на странице одна, выводится дважды из `<template id="form-tpl">` (первый экран и финал).

# Аналитика рынка Новосибирска 2026 — лендинг СОДА

Страница сбора заявок: в обмен на контакты менеджер по продажам вручную отправляет PDF с региональной аналитикой по Новосибирску и ссылку на банк креативов СОДА.

**Страница:** https://nellkhamid-cmd.github.io/nsk-analytics-landing/

## Настройка

Все настройки — в блоке `CONFIG` в конце `index.html`:

- `endpoint` — адрес приёма заявок (POST, multipart/form-data). Пока пусто — форма показывает «Спасибо», но заявка никуда не уходит.
- `policyUrl`, `agreementUrl` — ссылки на политику и согласие (sodaa.ru).
- `metrikaId` — счётчик Яндекс Метрики, цель `lead`.
- `manager` — контакты менеджера в подвале.

Поля заявки: `name`, `phone`, `company`, `channel` (Telegram / WhatsApp / MAX / Почта), `email`, `consent`, `form`, `offer`, `page`, `sent_at`, `utm_*`.

`?noanim` в адресе — показать все блоки сразу (для скриншотов).
